# 星境

八字命盘的可视化呈现：**起境（你的生辰）→ 内景星图 → 命理与运势解读 → 诞生星轨** 四幕叙事。

参考 24 秒录屏与《星境复刻实施方案.md》复刻，技术栈自选：
React 18 + TypeScript + Vite + Canvas 2D + three.js。Canvas 层动效全部用 `requestAnimationFrame` 与 CSS 关键帧实现，未引入动画库。

## 快速开始

```bash
pnpm install
pnpm dev            # 开发服务器
pnpm build          # 类型检查 + 生产构建（输出 dist/）
pnpm preview        # 预览构建产物
pnpm test           # 单元测试
pnpm typecheck      # 仅类型检查
```

> **Windows 提示**：本机环境下 `edit` 类工具写临时文件时会被 Vite 的 FSWatcher 报 `EBUSY` 而崩溃。
> 若开发服务器意外退出，改用静态预览循环验证视觉效果：`pnpm build && pnpm exec vite preview --port 5299`。

## 四幕结构

| 幕 | 内容 |
|---|---|
| **01 起境** | 公历生日 / 出生时间 / 出生地时区 / 性别表单，右侧黄道环标出出生当日太阳所在宫位，金色主按钮「开启我的星境 ↗」 |
| **02 内景** | 中央打坐人形 + 环绕运行的星曜节点：十神（透干/藏干）青绿环、神煞紫色环（共 22 节点）。节点带引线流光，可拖拽环绕、滚轮缩放、双击聚焦、单击查看释义；人体对身后节点有半透明遮挡 |
| **03 命理与运势解读** | 四柱总览 / 五行力量分布 / 日主强弱 / 喜用忌神 / 十神格局 / 神煞要点 / 八步大运 / 流年五年，八节皆由该刻干支推演而来，页末附免责声明 |
| **04 诞生星轨** | three.js 日心 8 天体 3D 轨道，八颗行星与太阳均为程序化生成贴图（土星环带卡西尼缝）；进入视口自动起航并按「出生后 N 天」推进，滚轮缩放、双击聚焦行星，左下角星符可暂停/继续 |

四幕共用同一张固定星空背景（`position: fixed`），按阶段推进而非路由切换。

## 命理内核

零第三方依赖，全部自研（`src/domain/`）：

- **四柱**：立春分年、节气分月、日柱用 Julian Day Number 锚定甲子日、时干五日干推算，支持晚子时。
- **十神**：由日干对目标天干的五行生克与阴阳同异共同决定；透干（跳过日干本体）+ 藏干展开。
- **神煞**：数据驱动规则表，支持年/月/日/时支、年月日时干、三合、季节等多基准。

黄金用例（2001-01-01 12:00 UTC+8 女）：

```
四柱  庚辰 戊子 甲子 庚午
日主  甲 · 午时 · 属龙
旬空  戌 亥
十神  恰好 10 个（透干 3 + 藏干 7）
神煞  命中 12/14 = 85.7%
```

## 天文层

**铁律：星轨角速度必须使用真实公转周期**，即 `ω = 2π/T`，轨道半径的压缩只用于绘制、不影响角度。

角度推进是唯一公式（`src/domain/astro/orbit.ts`）：

```ts
bodyAngle(phase0, period, days) = phase0 + TAU * (days / DAYS_PER_YEAR) / period
```

由此水星与海王星的角位移比恒为 `164.8 / 0.241 ≈ 683.8`，即物理上限——实测两档天数均严格命中该比值（`test/astro.test.ts`）。

出生时刻的日心黄经由 `astronomy-engine` 计算（唯一的外部数据依赖）。

## 视觉标定

设计令牌在 `src/styles/tokens.ts`，内景 Canvas 坐标一律在 **1440×1080 参考画布**空间计算，再由 `ctx.setTransform` 一次性缩放到实际容器，因此标定值可原样复用。

| 项 | 值 | 来源 |
|---|---|---|
| 太阳圆心 | (693, 531) | 录屏逐帧测量 |
| 轨道 squash | 0.43 | 录屏垂直/水平半径比 |
| 推进速率 | 15 天/秒 | 录屏标题行逐秒 OCR 实测 |
| 背景 / 金 / 青绿 / 紫 | `#07080b` / `#d9b877` / `#6ee7b7` / `#a78bfa` | 实施方案设计令牌 |

### 行星贴图是预烘焙资产

进入星轨时**不能**现场逐像素生成贴图：11 张 1024×512 的贴图在主线程同步计算，实测会让页面冻结 **10.9 秒**（这正是「星轨加载不出来」的根因）。

因此贴图在构建期烘焙为 `public/textures/*.webp`（合计约 384 KB），运行时由 `src/render3d/textureManifest.ts` 按文件名直取，`planetMaterials.ts` 的 `preloadTextures()` 在首屏预载。修复后最长长任务从 **10905 ms 降到 95 ms**。

重新生成贴图：

```bash
node scripts/bake-textures.mjs
```

若资产缺失，运行时会自动回退到程序化生成（并 console.warn 一次），不会白屏，但会有明显卡顿。

## 工程约定

- **测试**：`test/` 下 4 个文件 123 项，覆盖四柱/十神/神煞黄金用例、天文角速度比值、运势推演。
- **验收脚本**：`scripts/` 下的 playwright 脚本按幕截图并抓运行时错误。它们依赖 dev-only 的探针页（`_probe/*.html`），因此需对 dev server 运行，预览服务只服务 `dist`。
- **无 git 历史包袱**：本项目首次入库即当前状态；早期重构期的 `.bak` 副本与 `_probe/`、`_shots/` 诊断产物均在 `.gitignore` 中排除。

## 已知限制

- **真太阳时未校正**：直接采用输入的当地钟表时间，与原片一致（界面上有明确声明）。
- **神煞规则弱证据**：不同流派口径不一，本项目按可解释的主流版本实现，以集合命中率作为验收口径。
- **大运为简化排法**：固定 1 岁起运、每步整十年，未做「从出生到交节天数 ÷ 3 = 起运岁」的折年换算（`src/domain/bazi/fortune.ts` 文件头有显式声明）。
- **地球大陆是程序化形似**：用球面高斯核塑形以控制大陆数量与拓扑，非真实地理数据（陆地 30.1%，真实 29.2%）。
- **星轨远景标牌有轻微互压**：木星与土星在默认视距下标签略有重叠，缩放后正常。
- **开发服务器 HMR 未完整验证**：受上述 Windows 文件锁问题影响，视觉验证全程走 `build + preview` 静态循环。
